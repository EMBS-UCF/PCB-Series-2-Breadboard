# PCB Series #2: Breadboard

This repository contains the presentation materials for the second workshop in our PCB series, conducted on 11/17/2026.

### Workshop Overview

Attendees built the ECG heartbeat flasher from the first workshop on a breadboard: a circuit that picks up the heart's electrical signal and blinks an LED with each beat. The workshop covers safety, the parts in the kit, how a breadboard is laid out, and then builds the circuit in five parts: power, picking up the signal, amplifying it, comparing it against a threshold to flash the LED, and testing with the electrode pads.

The first workshop in the series designs the same circuit's board in KiCad.

### Setup

The circuit runs on a 9 V battery only. Never connect it to anything plugged into the wall. It is not a medical device.
